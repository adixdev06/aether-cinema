# 🎬 Aether Cinema

A cinematic movie discovery platform built for personalized movie exploration.

## ✨ Features

- 🎬 Personalized movie recommendations
- 🌙 Mood-based movie discovery
- 🔍 Movie search and exploration
- 📖 Detailed movie pages
- ❤️ Watchlist / personal library
- 🧬 Movie DNA and taste profiling
- 🌌 Interactive movie universe
- 🎞️ Cinematic modern UI
- 📱 Responsive design

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB
